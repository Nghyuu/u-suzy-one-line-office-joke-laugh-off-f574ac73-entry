## Description

A program that writes one original one-line office joke — a sharp, surprising
punchline, clear on a single read — to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (one line, UTF-8).
